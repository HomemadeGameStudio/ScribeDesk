# ScribeDesk

A minimalist student workspace and stealth utility suite built with React, Tailwind, and a custom DOM cloaking layer. 

## Features
- **Omnibox Routing:** Fast command execution (`:`) and direct route navigation.
- **Tab Cloaking:** Instantly disguise browser titles and favicons.
- **Panic Key:** Hotkey activation (`Ctrl+Shift+Z`) for instant interface hiding.
- **Web-Port Integration:** Isolated app and game execution.

## Tech Stack
- React
- Tailwind CSS
- Vanilla JS (DOM manipulation & routing)
